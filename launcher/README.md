# Goal Setting launcher (Windows)
1. Copy this `launcher` folder anywhere on your PC.
2. Open `start-goal-app.vbs` in Notepad and confirm `APP_PORT` (and `START_CMD` if auto-detect is wrong).
3. Right-click `create-shortcut.ps1` > Run with PowerShell. Double-click **Goal Setting** on the Desktop.

The server runs hidden; use **Stop Goal Setting** (or `stop-goal-app.vbs`) to end it.
Server output goes to `goal-app.log` in the app folder.
