# Goal Setting - easy start
1. Copy both .vbs files INTO your "Goal Setting Server" folder (next to START SERVER.cmd).
2. Right-click "Goal Setting.vbs" > Send to > Desktop (create shortcut).
3. Double-click the shortcut. No cmd window; the browser opens by itself.
"Stop Goal Setting.vbs" shuts the server down (it ends all Node.js programs).
If it fails, Notepad opens with goal-app.log.
